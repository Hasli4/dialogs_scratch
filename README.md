# Диалоговый стол

Интерактивный конструктор диалогов в стиле Scratch.

- перетаскивание команд «говорить» и «ждать» на дорожки персонажей;
- изменение текста реплик и длительности пауз;
- выбор персонажа: мальчик, девочка или собака;
- сохранение плана диалога в браузере;
- предпросмотр готового сценария.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

При push в ветку `main` GitHub Actions собирает сайт и публикует его на GitHub Pages.
